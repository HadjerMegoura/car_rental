# DriveFlow

A car rental management application built with React and TypeScript.

## Project Goals

DriveFlow is a learning and portfolio project designed to explore
React development through the implementation of realistic features.

The project focuses on:

- Modern React development.
- TypeScript and type-safe API communication.
- Clean and maintainable frontend architecture.
- Authentication and authorization.
- Forms and validation.
- Asynchronous data fetching.
- Testing and debugging.
- AI-assisted software development.

## Tech Stack

### Frontend

- React
- TypeScript
- React Router
- Axios
- Tailwind css

### Backend

- Java
- Spring Boot
- Spring Security
- PostgreSQL

## Planned Features

### 1. Car Management

- Display available cars.
- View car details.
- Filter cars by brand and other criteria.
- Handle loading, error, and empty states.

### 2. Client Management

- Display clients.
- View client details.
- Search and filter clients.
- Create and update client information.

### 3. Booking Management

- Create a booking for a client and a car.
- Select rental start and end dates.
- Calculate the estimated rental price.
- Validate booking information.
- Prevent conflicting bookings.
- Display booking details and history.

### 4. Authentication

- Login and logout.
- Handle expired sessions.
- Protect routes.
- Handle unauthorized API responses.

### 5. Quality

- Unit and integration tests.
- Form validation.
- Error handling.
- Accessibility.
- Responsive design.
- Consistent code quality.

## Development Principles

- Prefer simple solutions over unnecessary abstractions.
- Keep components focused and maintainable.
- Use TypeScript to make contracts explicit.
- Avoid duplicated state.
- Test important business rules.
- Calculate authoritative booking prices on the backend.
- Review AI-generated code before accepting it.

## Learning Objectives

During development, I aim to understand:

- When and why to use React Hooks.
- How to structure components and manage state.
- How to handle API requests and asynchronous UI.
- How to build reusable forms and components.
- How to test React applications.
- How to use AI coding assistants responsibly.
